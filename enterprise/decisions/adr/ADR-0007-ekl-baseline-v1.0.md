
# ADR-0007: Enterprise Knowledge Language (EKL) Baseline v1.0
## Status
✅ Accepted

## Date
2026-07-23

## Context
The repository has evolved from a documentation structure into a complete framework for enterprise knowledge modeling, including vocabulary, ontology, metamodel, grammars, validation, projections, traceability, and lifecycle specifications.

## Decision
Rename the milestone to **Enterprise Knowledge Language (EKL) Baseline v1.0** to more accurately reflect what has been built.

## Rationale
- What we've built is a domain-specific language (DSL) for enterprise knowledge, not just a repository baseline
- Emphasizes that the framework is a complete language, not just a set of conventions
- Aligns with "Enterprise First" principle (EP-001)
- Differentiates framework (EKL) from content (Enterprise Knowledge Model)

## Consequences
- All future work focuses on completing the EKL semantic specifications
- Repository structure is **permanently frozen**
- EKL Baseline v1.0 replaces Architecture Baseline v1.0 as the stable framework milestone
