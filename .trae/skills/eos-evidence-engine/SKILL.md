# EOS Evidence Engine Skill

Turns static evidence archives into executable governance computation that can automatically verify requirement completion and calculate confidence scores.

## What it does
1. Aggregates all evidence types: implementation, test, runtime, public behavior, acceptance
2. Calculates confidence verdicts for each requirement
3. Validates evidence completeness and authenticity
4. Feeds verification results back into the EOS execution loop
5. Generates audit trails for all governance decisions

## When to invoke
- When building automated governance computation
- When implementing confidence scoring for requirements
- When verifying evidence completeness for deployments
- When creating audit trails for all changes
- When automating PASS/FAIL decisions without human intervention
