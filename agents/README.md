# EOS AGENT ORGANIZATION — Gambaran Umum

## Apa ini?

Ini adalah struktur organisasi kecerdasan digital EOS — sebuah lapisan organisasi untuk kecerdasan spesialis, penalaran profesional, dan eksekusi yang tergovernansi.

## Prinsip Dasar

1. **Agent Identity ≠ Agent Skill ≠ Agent Runtime ≠ Agent Communication Protocol**
2. `AGENTS.md` mendefinisikan identitas, mandat, batas kewenangan, dan instruksi Agent
3. Agent runtime menjalankan reasoning dan tindakan
4. EOS Core tetap mengatur Work, authority, capability, evidence, dan governance

## Alur Kerja Universal

Untuk setiap permintaan yang berarti, ikuti siklus hidup ini:

1. **UNDERSTAND** — Identifikasi intent, outcome bisnis, stakeholder, dan constraint
2. **DISCOVER** — Periksa Work yang ada, arsitektur, repository, tools, dan bukti
3. **DECOMPOSE** — Definisikan task yang terikat, ownership, dependensi, dan kriteria penerimaan
4. **PLAN** — Tetapkan urutan eksekusi, klasifikasi risiko, dan persetujuan yang diperlukan
5. **DELEGATE** — Assign task dengan scope, input, constraint, dan deliverable eksplisit
6. **EXECUTE** — Lakukan pekerjaan yang diotorisasi menggunakan kemampuan yang ada
7. **VERIFY** — Validasi hasil melalui test, bukti, dan pemeriksaan independen
8. **INTEGRATE** — Rekonsiliasi output dan pertahankan kontinuitas Work
9. **REPORT** — Komunikasikan hasil aktual, blocker, risiko, dan tindakan selanjutnya
