# MASTERPIECE PLAN — EOS FACE

## EOS Visual Experience System v1.0

### **From Work Reality Constitution → Production Runtime**

> **Status:** Master Product Blueprint
> **Primary objective:** Turn EOS FACE from a visual/product constitution into a production-grade runtime experience.
> **Core principle:** **Work is the center of gravity.** Everything else exists to help a real person move a real Work toward a verified outcome.

---

# 0. EXECUTIVE THESIS

EOS tidak membutuhkan “lebih banyak software”.

EOS membutuhkan **satu pengalaman yang membuat pekerjaan nyata terasa continuous**.

Produk seperti Linear, Notion, Asana, ClickUp, dan monday.com sangat kuat karena mereka membuat informasi dan collaboration mudah dipahami secara visual. EOS harus mengambil standar tersebut—clarity, hierarchy, speed, responsiveness, collaboration, polish—tetapi tidak mengadopsi primitive mereka secara mentah.

Mereka terutama mengorganisasi:

```text
Issue
Task
Project
Page
Workspace
Board
```

EOS mengorganisasi:

```text
                         WORK
                          │
             ┌────────────┼────────────┐
             ↓            ↓            ↓
          CONTEXT       ACTORS     COMMUNICATION
             │            │            │
             └────────────┼────────────┘
                          ↓
                     CURRENT REALITY
                          ↓
                      NEXT ACTION
                          ↓
                       COMMAND
                          ↓
                   STATE TRANSITION
                          ↓
                      ACTIVITY
                          ↓
                       EVIDENCE
                          ↓
                       OUTCOME
```

### Thesis EOS:

> **A Work should remain understandable, actionable, attributable, and provable even as people, systems, conversations, documents, and external institutions change.**

Maka:

# **EOS FACE bukan dashboard.**

# **EOS FACE adalah visual operating surface untuk Work Reality.**

# 2. EOS FACE CONSTITUTION

## Principle 01 — Work First

User tidak datang untuk:

> “mengelola database.”

User datang untuk:

> **menyelesaikan sesuatu.**

---

## Principle 02 — Reality Over Decoration

Visual harus merepresentasikan keadaan sebenarnya.

```text
UI claim
   ↓
runtime truth
```

Jika UI mengatakan:

```text
Approved
```

harus ada state/evidence yang mendukungnya.

---

## Principle 03 — One Work, Many Perspectives

Customer, lawyer, notary, operator, dan agent tidak memiliki Work berbeda.

Mereka memiliki:

```text
ONE WORK
```

dengan:

```text
different perspective
different responsibility
different authority
different next action
```

---

## Principle 04 — Context Before Complexity

Actor yang baru masuk ke Work harus dapat memahami:

```text
What is this?
Why does it exist?
What happened?
What is true now?
Who is involved?
What needs to happen next?
```

tanpa membaca seluruh history.

---

## Principle 05 — Action Must Be Real

```text
Button
 ↓
Command
 ↓
Validation
 ↓
State mutation
 ↓
Activity
 ↓
Evidence
```

React state saja tidak pernah dianggap sebagai completion.

---

## Principle 06 — Communication Belongs to Work

Tidak:

```text
Inbox → message → maybe Work
```

Tetapi:

```text
Work
 └── Communication
```

---

## Principle 07 — Evidence Is First-Class

Work yang selesai harus dapat menjawab:

> **Why should I believe this is done?**

---

## Principle 08 — Agent Is a Participant

AI bukan universe kedua.

Bukan:

```text
EOS
+
AI Chat
```

Tetapi:

```text
WORK
 └── EOS Agent
```

Agent:

```text
inspect
understand
recommend
execute when authorized
record evidence
```

---

## Principle 09 — Premium Means Clarity

EOS harus terasa premium.

Tetapi premium bukan:

```text
animation everywhere
gradients everywhere
decorative cards
```

Premium berarti:

```text
clear hierarchy
excellent spacing
fast interaction
calm surfaces
obvious actions
minimal cognitive load
```

---

## Principle 10 — Continuity Is the Product

Fitur individual bukan moat utama EOS.

Moat-nya:

> **Work continuity across actors, systems, communications, and execution.**
