# REQ-010: Location Filter untuk /community Page

## Status
✅ CLOSED & VERIFIED

## Requirement
**Tambahkan filter lokasi di halaman /community** agar pengguna dapat mencari anggota komunitas berdasarkan negara atau kota.

## Latar Belakang
Sebelum REQ-010, halaman /community hanya memiliki filter berdasarkan tipe anggota (researcher, professor, student) dan pencarian teks. Pengguna seringkali ingin mencari kolaborator berdasarkan lokasi geografis (Bandung, Jakarta, Singapura, dll). Filter lokasi adalah affordance pencarian yang paling sering diminta setelah filter tipe.

## Acceptance Criteria
1. ✅ Filter lokasi muncul di search bar halaman /community
2. ✅ Anggota terfilter sesuai lokasi yang dipilih
3. ✅ Integrasi dengan shared BaseSearchBar (tidak ada fork kode)
4. ✅ URL state management bekerja (lokasi terpilih muncul di query param ?location=)
5. ✅ Dapat di-bookmark dan di-share
6. ✅ Fallback behavior jika lokasi tidak tersedia
