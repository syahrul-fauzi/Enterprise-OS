
# LawyersHub User Journeys

## Core Vertical Slice (Sprint 1)
### User Journey: Anonymous Visitor → Complete Matter Creation

1. **Anonymous Visitor lands on LawyersHub**
2. **Visitor authenticates** (Sign In)
3. **Authenticated user creates new Workspace**
4. **User creates new Client**
5. **User creates new Matter**
6. **User uploads Document to the Matter**
7. **User reviews created Matter**
8. **User logs out**
